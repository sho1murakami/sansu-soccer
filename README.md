# さんすう サッカー ⚽

5さい向けの 1けた × 1けた の算数アプリです。iPad の Safari で使う想定の、HTML 1枚だけのWebアプリです。

## できること

- **たしざん / ひきざん / かけざん（九九）**：1回10問。かけざんは「〇のだん」か「ミックス」を選べます
- **サッカーボールの絵**：たし算は2つのかたまり、ひき算は✕で消える、かけ算は「〇こずつ × 〇つぶん」の列で表示。最初は「ボールを みる」ボタンで出すヒント（まちがえると自動で出ます）。設定で「いつも出す」にもできます。ボールをタッチすると声で数えます
- **読み上げ**：問題・正解（かけ算は九九のとなえ方）を読み上げ。速さは設定で変えられます（初期値 1.0）
- **ごほうび**：正解でゴール演出、10問ぜんぶ1回目で正解するとシール1枚。全46種類＋キラキラ（レア）
- **ランク**：たしざん・ひきざん・かけざん それぞれのシール枚数で、ルーキー（0）→ レギュラー（3）→ エース（10）→ キャプテン（30）→ スター（70）→ レジェンド（150）→ ワールドクラス（300）とランクアップ。トップ画面のプルダウンで見るランクを切り替え、「i」ボタンで一覧が見られます。開いたときは たしざん → ひきざん → かけざん の順に、ワールドクラスになったら次を表示します（設定で固定も可）
- **にがて対策**：まちがえた問題は次から出やすくなります

## 公開のしかた（GitHub Pages）

1. このフォルダを GitHub のリポジトリに push する
2. リポジトリの Settings → Pages → Branch を `main` / `/ (root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます

iPad の Safari で開いたら、共有ボタン →「ホーム画面に追加」がおすすめです（全画面で使えて、記録も消えにくくなります）。

## 記録について

シールや設定はその iPad の Safari の中（localStorage）に保存されます。サーバーには何も送りません。
Safari の「履歴とWebサイトデータを消去」をすると記録も消えます。
