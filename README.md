# がくしゅうアプリ（5さい向け） ⚽

5さい向けの 1けた × 1けた の算数アプリです（アプリ名は9さい向けと同じ「がくしゅうアプリ」）。iPad の Safari で使う想定の、HTML 1枚だけのWebアプリです。

## できること

- **たしざん / ひきざん / かけざん（九九）**：1回7問。かけざんは「〇のだん」か「ミックス」を選べます
- **サッカーボールの絵**：たし算は2つのかたまり、ひき算は✕で消える、かけ算は「〇こずつ × 〇つぶん」の列で表示。最初は「ボールを みる」ボタンで出すヒント（まちがえると自動で出ます）。設定で「いつも出す」にもできます。ボールをタッチすると声で数えます
- **読み上げ**：問題・正解（かけ算は九九のとなえ方）を読み上げ。速さは設定で変えられます（初期値 1.0）
- **ごほうび**：正解でゴール演出、7問中4問以上を1回目で正解するとシール1枚（かけざんの1の段は練習用でシールなし）。シールは全100種類（9さい向けアプリと同じ）。グレードは ノーマル（78種類）・レア（16種類）・スーパーレア（6種類）で、どのシールも12%でキラキラになります。まだ持っていないシールは2.5倍出やすく、全問正解でもらうシールはスーパーレアが1.5倍出やすくなります。シールちょうの「🎲 でる かくりつ」で、今の出現確率を見られます
- **優先テーマ**：初期値はたしざん（おうちの方へ画面で変更可）。その日に優先テーマのシールを5枚集めるまで、ほかの計算ではシールがもらえません。選ぶと確認のポップアップが出て、シールなしの練習はできます
- **ランク**：たしざん・ひきざん・かけざん それぞれのシール枚数で、ルーキー（0）→ レギュラー（15）→ エース（40）→ キャプテン（80）→ スター（130）→ レジェンド（200）→ ワールドクラス（300）とランクアップ。トップ画面のプルダウンで見るランクを切り替え、「i」ボタンで一覧が見られます。開いたときは たしざん → ひきざん → かけざん の順に、ワールドクラスになったら次を表示します（設定で固定も可）
- **にがて対策**：まちがえた問題は次から出やすくなります
- **ゲーム**：トップ画面の下の「ゲーム」から、めいろ・しんけいすいじゃく・IQテスト と むずかしさ（やさしい・ふつう・むずかしい）を選びます
  - **めいろ**：1 → 2 → 3 … の順に、すべてのマスを1回ずつ通って最後の数字までつなぐパズル。指でなぞります。やさしい（5×5）・ふつう（6×6・かべあり）・むずかしい（7×7・かべあり）
  - **しんけいすいじゃく**（どうぶつカード）：1人で、うらがえしのカードを2枚ずつめくって同じ動物のペアをすべて見つけます。むずかしさごとのカードの枚数は、はじめは やさしい 12枚（6ペア）・ふつう 16枚（8ペア）・むずかしい 24枚（12ペア）。おうちの方へ画面で、それぞれ 12・16・24・36・48枚（6・8・12・18・24ペア）から選べます。動物は48種類から毎回ランダム。ベストタイムは枚数ごとに記録します。カードは iPad の絵文字の動物に、すむ場所の色（草原・森・サバンナ・水べ・海・氷）の背景と名前をつけたもので、めくると名前を読み上げます。ヒント「ちらっと みる」（1回3つまで）で、のこりのカードを2秒だけ見られます。タイムとちょうせん回数を記録します（すうどくは5さいには難しかったため入れ替えました）
  - **IQテスト**（5さい向けの問題）：かずの ならび・ならびのきまり・なかまはずれ・かたち・3×3パズル・かぞえる・シーソー・じゅんばん・くらべる の9種類から毎回7問。えらんでから「けってい」で、7問中4問以上正解でクリア。むずかしさごとの中身は次のとおりです
    - やさしい：1ずつ ふえる数、AB のくりかえし、どうぶつ・くだものなどの なかまはずれ、おなじ形さがし、よこが同じ3×3、2種類から かぞえる（5〜7こ）、シーソーで おもいほう、ひだりから○ばんめ、どっちが おおい
    - ふつう：1ずつ へる・2ずつ ふえる数、AAB・ABC、なかまを ふやした なかまはずれ、さかさまの形、よこ＝形・たて＝色の3×3、3種類から かぞえる（8〜10こ）、シーソーで かるいほう、みぎから○ばんめ、どっちが すくない
    - むずかしい：2・5・10ずつの数（とちゅうが ？のことも）、4こ1組のくりかえし、かずが ちがう まとまり、かがみ・¼かいてん、色が1つずつ入る3×3、11〜14こから かぞえる、シーソー2つで いちばん おもいもの、○○は なんばんめ、いくつ おおい
  - はじめは、その日の「きょうのミッション」（優先テーマのシール5枚）が終わるまで遊べません（おうちの方へ画面でオフにできます）
  - めいろ・しんけいすいじゃく・IQテストは、それぞれ1日3回まで（おうちの方へ画面で 1・2・3・5回・制限なし に変更でき、今日の回数のリセットもできます）。遊びはじめたとき（めいろは線を引きはじめた、しんけいすいじゃくはカードをめくった、IQテストは1問目に答えたとき）に1回と数えるので、選びまちがえてすぐ戻ったときは数えません。ゲームの画面に「きょう あと ○かい」が出て、使いきったゲームは「きょうは おしまい」になります
  - クリアするとコイン1枚。コイン10枚で、トップ画面の「🪙」ボタンからシール1枚（ランダム）と交換できます（自動では交換しません）。おうちの方へ画面でコインをオフにできます。むずかしさごとにベストタイムを記録します
- **おうちの方へ画面のパスワード**：数字4〜8けたのパスワードで開きます。最初に開いたときに決め、おうちの方へ画面で変更できます。5回まちがえると60秒入れなくなります。子どもに解かれないよう、忘れたときに決め直す方法は用意していません（忘れると おうちの方へ画面は開けなくなりますが、遊び・シールの記録はそのまま使えます）。パスワードはメモしておいてください。パスワードはそのままの文字では保存せず、バックアップにも同じパスワードが引きつがれます
- **記録のバックアップ（引っこし）**：おうちの方へ画面で、シール・コイン・ゲームの記録・設定をまとめて書き出し／読み込みできます（9さい向けアプリと同じしくみ。9さい向けのバックアップは読み込めないようにしています）

## 公開のしかた（GitHub Pages）

1. このフォルダを GitHub のリポジトリに push する
2. リポジトリの Settings → Pages → Branch を `main` / `/ (root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます

iPad の Safari で開いたら、共有ボタン →「ホーム画面に追加」がおすすめです（全画面で使えて、記録も消えにくくなります）。

## 記録の引っこし（バックアップ）

ホーム画面のアイコンは、アイコンごとに記録が別々に保存され、アイコンを削除すると記録も消えます。アイコンを作り直すとき（アプリの名前を「がくしゅうアプリ」に変えたいときなど）は「おうちの方へ」画面の「記録のバックアップ」で引っこしてください。

1. 今のアイコンで開き、「コピー」（または「ファイルに保存」）
2. Safari でアプリを開き、共有ボタン →「ホーム画面に追加」で新しいアイコンを作る
3. 新しいアイコンで開き、「はりつけ」（または「ファイルから」）→「読み込む」
4. 新しいアイコンでシールが戻ったのを確かめてから、古いアイコンを削除

## 記録について

シールや設定はその iPad の Safari の中（localStorage）に保存されます。9さい向けの「がくしゅうアプリ」とは別の記録です。サーバーには何も送りません。
Safari の「履歴とWebサイトデータを消去」をすると記録も消えます。
