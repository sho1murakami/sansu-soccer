# さんすうアプリ ⚽

5さい向けの 1けた × 1けた の算数アプリです。iPad の Safari で使う想定の、HTML 1枚だけのWebアプリです。

## できること

- **たしざん / ひきざん / かけざん（九九）**：1回7問。かけざんは「〇のだん」か「ミックス」を選べます
- **サッカーボールの絵**：たし算は2つのかたまり、ひき算は✕で消える、かけ算は「〇こずつ × 〇つぶん」の列で表示。最初は「ボールを みる」ボタンで出すヒント（まちがえると自動で出ます）。設定で「いつも出す」にもできます。ボールをタッチすると声で数えます
- **読み上げ**：問題・正解（かけ算は九九のとなえ方）を読み上げ。速さは設定で変えられます（初期値 1.0）
- **ごほうび**：正解でゴール演出、7問中4問以上を1回目で正解するとシール1枚（かけざんの1の段は練習用でシールなし）。シールは全100種類（9さい向けアプリと同じ）。グレードは ノーマル（78種類）・レア（16種類）・スーパーレア（6種類）で、どのシールも12%でキラキラになります。まだ持っていないシールは2.5倍出やすく、全問正解でもらうシールはスーパーレアが1.5倍出やすくなります。シールちょうの「🎲 でる かくりつ」で、今の出現確率を見られます
- **優先テーマ**：初期値はたしざん（おうちの方へ画面で変更可）。その日に優先テーマのシールを5枚集めるまで、ほかの計算ではシールがもらえません。選ぶと確認のポップアップが出て、シールなしの練習はできます
- **ランク**：たしざん・ひきざん・かけざん それぞれのシール枚数で、ルーキー（0）→ レギュラー（15）→ エース（40）→ キャプテン（80）→ スター（130）→ レジェンド（200）→ ワールドクラス（300）とランクアップ。トップ画面のプルダウンで見るランクを切り替え、「i」ボタンで一覧が見られます。開いたときは たしざん → ひきざん → かけざん の順に、ワールドクラスになったら次を表示します（設定で固定も可）
- **にがて対策**：まちがえた問題は次から出やすくなります
- **ゲーム**（9さい向けアプリと同じ3つ）：トップ画面の下の「ゲーム」から、めいろ・すうどく・IQテスト と むずかしさ（やさしい・ふつう・むずかしい）を選びます
  - **めいろ**：1 → 2 → 3 … の順に、すべてのマスを1回ずつ通って最後の数字までつなぐパズル。指でなぞります。やさしい（5×5）・ふつう（6×6・かべあり）・むずかしい（7×7・かべあり）
  - **すうどく**：6×6（ふとい枠は2×3）。メモ・もどす・ヒント（1回3つまで）つき。答えが1通りになる問題を自動で作ります
  - **IQテスト**：すうれつ・ならびのきまり・なかまはずれ・かたちの回転と鏡・3×3パズル・かぞえる・てんびん・ようび から毎回7問。4択で、7問中4問以上正解でクリア
  - はじめは、その日の「きょうのミッション」（優先テーマのシール5枚）が終わるまで遊べません（おうちの方へ画面でオフにできます）
  - クリアするとコイン1枚。コイン10枚で、トップ画面の「🪙」ボタンからシール1枚（ランダム）と交換できます（自動では交換しません）。おうちの方へ画面でコインをオフにできます。むずかしさごとにベストタイムを記録します
- **おうちの方へ画面のロック**：開くときに「2けた × 1けた」の計算を答えます（暗証番号はないので、忘れる心配がありません）

## 公開のしかた（GitHub Pages）

1. このフォルダを GitHub のリポジトリに push する
2. リポジトリの Settings → Pages → Branch を `main` / `/ (root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます

iPad の Safari で開いたら、共有ボタン →「ホーム画面に追加」がおすすめです（全画面で使えて、記録も消えにくくなります）。

## 記録について

シールや設定はその iPad の Safari の中（localStorage）に保存されます。サーバーには何も送りません。
Safari の「履歴とWebサイトデータを消去」をすると記録も消えます。
